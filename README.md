# PawSnap

Red social para compartir publicaciones de mascotas. Proyecto académico hecho con HTML, CSS y JavaScript.

## Cómo usarlo

Las funciones solo trabajan si la página se abre con **Go Live** (extensión *Live Server* de VS Code):

1. Abrir la carpeta del proyecto en VS Code.
2. Instalar la extensión **Live Server**.
3. Clic derecho en `index.html` → **Open with Live Server** (o el botón **Go Live** de la barra inferior).

Si se abre con doble clic en el archivo, las funciones no funcionarán correctamente.

## Funcionalidades

- **Publicaciones dinámicas:** se crean con JavaScript a partir de un arreglo (usuario, contenido, categoría y "Me gusta").
- **Crear publicación:** formulario con validación; la publicación nueva aparece automáticamente en Inicio y Publicaciones.
- **Imagen o video:** si se agrega un enlace de imagen, video o YouTube, se muestra en la publicación.
- **Me gusta:** suma o resta y actualiza el contador.
- **Eliminar:** solo se pueden eliminar las publicaciones creadas por el usuario.
- **Filtrar por categoría:** Todos, Caninos, Felinos y Roedores.
- **Buscador del encabezado:** filtra las publicaciones por usuario o texto.
- **Collar virtual:** vista previa en vivo de la placa y guardado de los datos con validación.

## Páginas

Inicio, Publicaciones, Crear publicación, Desaparecidos, Collar virtual, Perfil, Acerca de, Iniciar sesión y Crear cuenta.
